# Ultimate Modular Men — Quaternius

Official source: https://quaternius.com/packs/ultimatemodularcharacters.html
Downloaded 2026-11-11 from the author's linked public Drive folder:
https://drive.google.com/drive/folders/1USAAquX2JJWuA2m6zol0KUkFe3UkZ8zX

Original: All together / Blends / Humans_Master.blend (CC0; see License.txt).
Exported with Blender 4.3 using scripts/export-modular-characters.py.

- 11 outfits with Head, Body, Legs (Farmer_Pants), and Feet modules.
- Additional Horse_Head and Backpack.
- Original shared skeleton and all 24 animation clips.
- Original flat colors baked into vertex colors, one shared material.
- Sword and Pistol props omitted; weapon poses preview without a weapon.

Blender modifiers are applied to include mirrored geometry. Only selected modules are rendered.
Models load on demand in the character lab and when players appear in a match.
The saved outfit is sent when joining a multiplayer room.
